# Coffee-Shop-sales

#Tell me about your project

I worked on a coffee shop sales analysis project using Excel. The main objective of this project was to analyze sales performance, customer orders, and product trends to get business insights.
First, I cleaned and organized the raw transaction data in Excel. The dataset included transaction quantity, store location, product category, product type, bill amount, date, day, month, and order time.
Then, I used Pivot Tables to analyze different KPIs like:

Total Sales → around $698K
Total Footfall → 149K+ customers
Average Bill per Person
Average Order per Person

I also analyzed:

Sales by store location
Top 5 selling products
Category-wise sales performance
Order trends based on weekdays
Peak order hours
Size-wise order distribution (large, regular, small)

After analysis, I created an interactive dashboard using charts, slicers, and pivot tables, where users can filter data by month and weekday to understand sales trends easily.
